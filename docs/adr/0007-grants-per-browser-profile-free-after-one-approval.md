# 0007: Grants per browser profile, free after one approval

Status: accepted, 2026-11-16

## Context

Approving every fill is tiring; never approving is unsafe.

## Decision

Grants belong to a profile and a site, approved once with Touch ID, then free. Per grant ask every fill and a global strict mode add gates; turning strict mode off needs Touch ID.

## Why

Matches daily use; site binding, never returning values and the audit log stay on regardless.
